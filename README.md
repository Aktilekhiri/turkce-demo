# Alatoo Türkçe — демо (A1)

Статический прототип обучающей платформы по книге «Yabancılar İçin Temel Seviye Türkçe» (Ala-Too, 2026).
Без сборки и зависимостей: HTML + CSS + JS.

## Запуск
Откройте `index.html` в браузере или `python3 -m http.server` в папке проекта.

## Деплой
GitHub Pages или Cloudflare Pages: корень репозитория, команда сборки не нужна.

## Что внутри
- `content.js` — весь контент (темы, слова на 4 языках, диалоги). Позже заменяется на API/базу.
- `app.js` — экраны: темы → слова / диалог / упражнения / словарь; очки и прогресс в localStorage.
- Демо-темы: «Renkler» (цвета) и «Tanışma ve selamlaşma» (знакомство).

## Ограничения демо
- Нет регистрации, ролей Admin/Student, сертификата.
- Произношение: синтез речи браузера (tr-TR), не записи.
- Видео в диалогах — заглушка. Картинки из книги пока не подключены (цвета и эмодзи).
- 2 типа упражнений из 4.
